                                 PLANETARY FACT

An interactive, responsive website for exploring the eight planets of our solar system. Pick a planet and switch between **Overview**, **Internal Structure**, and **Surface Geology** views to see images, descriptions, and key facts such as rotation time, revolution time, radius, and average temperature.

Built with **HTML, CSS, and vanilla JavaScript** as a group frontend project.

Live Demo: [https://your-deployment-link.com]
Githug Repo: (https://your-deployment-link.com)

                        FEATURES

- Browse all 8 planets through a navigation menu
- Three content tabs per planet: Overview, Internal Structure, Surface Geology
- Planet-specific imagery, descriptions.
- Key statistics for each planet (rotation, revolution, radius, temperature)
- Unique accent color for each planet
- Fully responsive layout for mobile, tablet, and desktop
- Theme Toggling [Dark/light mode]
- Hover and active states on interactive elements

                            TECH STACK

| HTML5 | Page structure and semantic markup.
| CSS3 | Styling, layout (Flexbox/Grid), responsiveness, Theme styling.
| JavaScript (ES6+) | Dynamic content rendering, interactivity and Theme Toggling.
| JSON | Planet data storage.
